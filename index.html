Voice-to-SQL Inventory Management System

Natural Language Inventory Management for Kirana Stores

A full-stack inventory management system that allows shopkeepers to update inventory using natural language voice or text commands in Hinglish and Tanglish.

The system combines speech recognition, rule-based intent extraction, RAG-based SQL generation and SQL validation to convert natural language commands such as "50 kg atta add karo" into safe database operations.

Built with React, Vite, FastAPI, SQLite, FAISS, RAG, Sarvam ASR, Groq LLaMA and Ollama. The platform also provides sales analytics, demand forecasting, customer behaviour insights and product recommendations.

Tech: React · Vite · FastAPI · Python · SQLite · FAISS · RAG · LLMs · REST APIs

Distributed Image Processing System

Role: Backend / Distributed Systems

Built a distributed image processing system using Apache Kafka where a master node divides images into tiles and distributes processing tasks across worker nodes.

Workers process image segments in parallel and the master reconstructs the final image. Kafka provides asynchronous communication and enables the system to handle processing workloads independently across nodes.

Tech: Apache Kafka · Python · OpenCV · Docker · Distributed Systems
